# Roadmap

## Guiding Principles

- Deliver a working product early.
- Prioritize engineering quality over feature count.
- Keep the architecture modular.
- End every milestone with a deployable application.
- Improve iteratively through evaluation and feedback.

---

## Milestone 1 — MVP

### Goal

Deliver a publicly accessible RAG chatbot that demonstrates an end-to-end AI application.

### Deliverables

- Engineering planning and documentation.
- Project scaffold.
- Knowledge base ingestion.
- Document chunking.
- Embedding generation.
- ChromaDB integration.
- RAG pipeline.
- Gradio user interface.
- Docker containerization.
- Deployment on Hugging Face Spaces.

---

## Milestone 2 — Engineering Quality

### Goal

Improve software engineering maturity and development workflow.

### Deliverables

- Python tooling (Ruff, mypy, pytest).
- Pre-commit hooks.
- GitHub Actions CI.
- Logging.
- Configuration management.
- Expanded documentation.
- Unit and integration tests.

---

## Milestone 3 — AI Quality

### Goal

Improve retrieval quality, response quality, and evaluation.

### Deliverables

- Evaluation dataset.
- Retrieval evaluation framework.
- Prompt versioning.
- Improved chunking strategy.
- Metadata filtering.
- Hybrid retrieval.

---

## Milestone 4 — Production Readiness

### Goal

Operate the application using production-oriented AI engineering practices.

### Deliverables

- Monitoring.
- Usage analytics.
- Cost tracking.
- User feedback collection.
- Performance optimization.
- Security improvements.

---

## Future Enhancements

- Multi-document knowledge base.
- GitHub repository ingestion.
- Personal website integration.
- Conversation memory.
- Voice interface.
- Multi-model support.
- Admin dashboard.
- Authentication and authorization.

---

## Definition of Done

A milestone is complete when:

- Objectives have been achieved.
- Relevant documentation has been updated.
- Required ADRs have been created or updated.
- Code has been reviewed and merged.
- Tests pass, where applicable.
- The application remains deployable.
- GitHub Project reflects the completed work.
- All related issues have been closed.
